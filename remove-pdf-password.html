About this tool

If you have a password-protected PDF that you can already open but find it inconvenient to enter the password every time, enter the known password here to produce an unlocked copy. This works only when you know the password; it is not a password recovery or bypass tool, and it should only be used on documents you are entitled to access.

How to remove a password from a PDF you own

  1. Load the protected PDF by clicking the drop area or dragging it in.
  2. Enter the password you already know in the password field.
  3. Click “Unlock & download”.
  4. An unlocked copy, with no password required to open, downloads to your device.

Is it really private?

Yes. Unlike most online PDF services, this tool does not upload your file to a server. The file is read into your browser's memory on your own computer or phone, processed there, and handed straight back to you as a download. We never receive, see, store, or transmit it. Closing or refreshing the page clears it from memory.

Frequently asked questions

Can this recover a password I forgot?

No. This tool only removes protection when you enter the correct password. It cannot crack, guess, or recover an unknown password, and must only be used on documents you are entitled to open.

Is it legal to remove a PDF password?

It is intended only for documents you own or are authorised to access, where you already know the password. Using it to open files you are not entitled to access is prohibited and may be illegal in your jurisdiction.

Is my protected file uploaded?

No. The PDF is decrypted with your password inside your own browser and is never sent to a server, which is important for sensitive protected documents.

Why does the unlocked file look like images?

The unlocked copy is rebuilt page by page so it always opens reliably without a password. The pages are images, which is fine for viewing and printing but not for copying text out.

What if the password is wrong?

You will see a clear message that the password is incorrect, and no file is produced. Re-enter the correct password and try again.
