    About this tool

    Add the PDFs you want to join, arrange them in the order you need, and download one combined file. Because the work is done in your browser there is no file-size server limit and nothing you merge is ever transmitted or stored by us.

    How to merge PDF files

    1. Click the drop area or drag your PDF files in. Add as many as you need.
    2. The files are listed in the order they will be joined; remove any with the ✕.
    3. Click “Merge into one PDF”.
    4. A single combined PDF downloads to your device.

    Is it really private?

    Yes. Unlike most online PDF services, this tool does not upload your file to a server. The file is read into your browser's memory on your own computer or phone, processed there, and handed straight back to you as a download. We never receive, see, store, or transmit it. Closing or refreshing the page clears it from memory.

    Frequently asked questions

    Is there a file size or page limit?

    There is no server limit because nothing is uploaded — merging happens in your browser. Very large files are limited only by your own device's memory.

    Are my files uploaded when I merge them?

    No. Every file stays on your device. The merge is done locally in the browser and the combined file is handed straight back to you.

    Can I change the order of the PDFs before merging?

    Yes. The list shows the join order; remove and re-add files to arrange them the way you want before merging.

    Does merging reduce quality?

    No. Pages are copied as-is into the new file, so text and images keep their original quality.

    Can I merge password-protected PDFs?

    Remove the password first using the Remove Password tool, for files you are authorised to open, then merge the unlocked copies.
